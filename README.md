# Gears of War 2 : Hollow 日本語音声化ツール

PC 非公式移植版『Gears of War 2 : Hollow』のインゲーム音声を、Xbox 360 版
『Gears of War 2』日本語吹き替え版の音源に差し替えるためのツールです。

キャンペーンの台詞 8,123 本、44 パッケージを日本語に差し替えます。
ゲームの実行ファイルは改変しません。

事前レンダリングのカットシーンは英語のままです（「既知の制約」を参照）。

## 安全上の注意

- **導入前に控えを取ってください。** 手順 2 がそれにあたります。
  このツールはゲームの音声ファイルを**同じ名前で上書きします。**
  控えが無いと元に戻せません。
- **作業中はゲームを終了しておいてください。** 起動しているとファイルが掴まれて
  書き換えられません。エラーダイアログが出たままでも掴まれます。
- **手順 8 の確認を飛ばさないでください。** 整合性の取れていないファイルを入れると、
  ゲームが起動時に落ちます。手順 9 は置く直前にも同じ検査を掛けて、
  1 件でも合わなければ何も置かずに中止します。

## 用意するもの

| もの | 用途 |
|---|---|
| Gears of War 2 : Hollow | 差し替え先 |
| Gears of War 2 日本語版（Xbox 360）の ISO イメージ | 音源 |
| 空き容量 約 15 GB | ISO 7 GB ＋ 展開したもの 6.6 GB ＋ 途中で作るファイル約 1.5 GB |
| Python 3.10 以上 | **Python 同梱版の zip を使う場合は要りません**（[PYTHON.md](PYTHON.md)） |
| [extract-xiso](https://github.com/XboxDev/extract-xiso) | 手順 1 で使います |
| [Unreal Package Decompressor](https://www.gildor.org/downloads)（`decompress.exe`） | 手順 3 で使います |
| [umodel (UE Viewer)](https://www.gildor.org/en/projects/umodel) | 手順 4 で使います |
| [vgmstream](https://vgmstream.org/) | 手順 6 で使います |
| [ffmpeg](https://ffmpeg.org/download.html)（libvorbis 入りのもの） | 手順 6 で使います |

下の 4 つはどれも zip で配られています。落としたら展開して、場所を覚えておいてください。
どこに置いても構いません。あとで設定ファイルにその場所を書きます。

導入してもゲームフォルダの容量はほとんど増えません。同じ名前のファイルを差し替えるためです。

## 準備

### 1. 設定ファイルを作る

このフォルダにある `config.ini.example` を**コピーして**、
コピーしたほうの名前を `config.ini` に変えます。

> **ここが一番つまずきやすいところです。**
> Windows は最初の状態だとファイルの種類を表す部分（拡張子）を隠しています。
> メモ帳の「名前を付けて保存」で作ると、見た目は `config.ini` でも
> 実際は `config.ini.txt` になっていて、読み込まれません。
>
> `config.ini.example` を右クリック →「コピー」、
> 同じ場所で右クリック →「貼り付け」、
> できたファイルの名前を `config.ini` に変える。この手順なら失敗しません。

できた `config.ini` を右クリックして「プログラムから開く」→「メモ帳」で開き、
中身を自分の環境に合わせて書き換えます。

```ini
[paths]
hollow   = C:\Games\Gears of War 2 - Hollow
jpn_only = D:\gow2\jpn_only
work     = D:\gow2\work

[tools]
decompress = D:\gow2\tools\decompress.exe
umodel     = D:\gow2\tools\umodel_64.exe
vgmstream  = D:\gow2\tools\vgmstream-cli.exe
ffmpeg     = D:\gow2\tools\ffmpeg.exe
```

| 項目 | 何を書くか |
|---|---|
| `hollow` | Hollow を入れた場所。`GoW2Hollow_Launcher.exe` があるフォルダ |
| `jpn_only` | ISO から取り出した日本語音声を入れるフォルダ。手順 1 で作ります |
| `work` | 作業用のフォルダ。空の状態で新しく作ります。ここに 1.5 GB ほど使います |
| `decompress` | 展開した Unreal Package Decompressor の中にある `decompress.exe` の場所 |
| `umodel` | 展開した umodel の中にある `umodel_64.exe` の場所（32bit 版なら `umodel.exe`） |
| `vgmstream` | 展開した vgmstream の中にある `vgmstream-cli.exe` の場所 |
| `ffmpeg` | 展開した ffmpeg の中にある `ffmpeg.exe` の場所 |

**パスはエクスプローラからコピーしたまま貼り付けて構いません。**
`\`（円マーク）のままで動きます。右クリックの「パスのコピー」で付いてくる
`"`（引用符）も、末尾の `\` も、付いたままで構いません。

保存するときの文字コードは、UTF-8 でも Shift-JIS でも読めます。

`;` で始まる行は説明です。消しても残しても構いません。
`=` の右側だけを書き換えてください。

### 2. 環境を確認する

**`00_環境を確認する.bat` をダブルクリックします。**

必要なものが揃っているか、設定ファイルの書き間違いが無いか、
空き容量は足りるかまで一度に調べます。**ゲームのフォルダには何も書き込みません。**

**`NG` が 1 つでも出ていたら、直してから先に進んでください。**
何が足りないか、どう直すかが画面に出ます。
このあとの工程は 1 時間以上かかるので、途中で止まらないよう先に潰しておきます。

手順 1 がまだなら「日本語音声パッケージが見つかりません」と出ます。それで正常です。

## 手順の進め方

**手順 2 から 9 までは、番号の付いた `.bat` ファイルをダブルクリックするだけです。**
順番に実行していきます。画面は自動では閉じないので、中身を読んでから閉じてください。

| ファイル | 手順 |
|---|---|
| `02_バックアップを取る.bat` | 2 |
| `03_360パッケージを展開する.bat` | 3 |
| `04_音声を取り出す.bat` | 4 |
| `05_対応表を作る.bat` | 5 |
| `06_Oggにする.bat` | 6 |
| `07_パッケージを作る.bat` | 7 |
| `08_最後の確認をする.bat` | 8 |
| `09_ゲームに置く.bat` | 9 |
| `98_音が出ないとき.bat` | ゲームの音が全部鳴らないとき |
| `99_元に戻す.bat` | 日本語化をやめるとき |

**手順 1 だけは、別のソフトを直接使うので黒い画面が必要になります。**

### 黒い画面（コマンドプロンプト）の出し方

1. エクスプローラで、目的のフォルダを開きます
2. 上のほうにある、フォルダの場所が書かれた細長い欄をクリックします
3. 文字が選ばれた状態になるので、そこに `cmd` と入力して Enter キーを押します
4. 黒い画面が開きます。ここに文字を打って Enter を押すと実行されます

**開いたフォルダの中で実行される**のがこのやり方の利点です。
使い終わったら右上の × で閉じて構いません。

## 手順

### 1. ISO を展開する

展開した `extract-xiso` の中にある `extract-xiso.exe` を、
**ISO と同じフォルダにコピーしておいてください。**

> **ISO のファイル名にスペースが入っていると失敗します。**
> スペースがあるときは、先に `gow2.iso` のようなスペースの無い名前に変えてください。
> 変えるのはファイル名だけで、中身は関係ありません。

そのフォルダで黒い画面を出して、次のように打って Enter を押します。
`gow2.iso` のところは自分の ISO のファイル名に置き換えてください。

```
extract-xiso -x gow2.iso
```

しばらくかかります。終わると、ISO の中身がフォルダとして出てきます。
`GearGame` の下の `CookedXenon` というフォルダに、`.xxx` というファイルが 1,487 本あります。

このうち、**名前が `_LOC_jpn.xxx` で終わる 391 本**が日本語音声の入ったファイルです。
`_LOC_int.xxx`（英語版）も同じ数だけありますが、こちらは要りません。

エクスプローラで `CookedXenon` を開き、**右上の検索欄に `_LOC_jpn` と入力する**と、
その 391 本だけが表示されます。全部選んでコピーしてください。

貼り付け先は、新しく作ったフォルダです。どこでも構いません。
**その場所を `config.ini` の `jpn_only` に書きます。**

`00_環境を確認する.bat` をもう一度実行して、
「日本語音声パッケージ 391 本」と出れば手順 1 は完了です。

**ここまで来たら、展開した ISO の中身は消して構いません。**
このあと使うのはコピーした 391 本（約 220 MB）だけです。

### 2. 控えを取る

**`02_バックアップを取る.bat` をダブルクリックします。**

日本語化する前の音声ファイル 45 本を、作業用フォルダの `original_Sounds_INT` に控えます。

**このツールは同じ名前のファイルを上書きします。ここで控えを取らないと元に戻せません。**

一度控えたファイルは二度と上書きしません。日本語化したあとにもう一度実行しても、
日本語版で控えを潰してしまうことはありません。

### 3. 360 側のパッケージを展開する

**`03_360パッケージを展開する.bat` をダブルクリックします。**

手順 1 で集めた 391 本は圧縮されているので、`decompress.exe` で展開します。

`decompress.exe` は**フォルダをまとめて処理できません。** 渡せるのはパッケージ 1 本だけです。
このファイルが 391 本を 1 本ずつ渡します。数分かかります。

途中で閉じてしまっても、もう一度ダブルクリックすれば続きから進みます。

### 4. 日本語音声を取り出す

**`04_音声を取り出す.bat` をダブルクリックします。**

作業用フォルダの `snd_jpn` に音声ファイルが出ます。
16,000 本ほど出ていれば正常に動いています。本数が多いので時間がかかります。

ここも途中で閉じて構いません。もう一度実行すれば続きから進みます。

### 5. 対応表を作る

**`05_対応表を作る.bat` をダブルクリックします。**

360 側と Hollow 側で、どの音声がどこに入っているかを突き合わせます。

`matched: 8,123` と出ていれば想定どおりです。

### 6. Ogg Vorbis にする

**`06_Oggにする.bat` をダブルクリックします。**

Hollow 側が読める形式に変換します。8,122 本を変換するので 10〜20 分かかります。

`failed=0` で終わることを確認してください。

### 7. パッケージを組み立てる

**`07_パッケージを作る.bat` をダブルクリックします。**

控えておいたファイルをひな形にして、音声を日本語に差し替えたものを作業用フォルダに作ります。
44 個・約 405 MB になります。

**この段階ではゲームのフォルダに一切書き込みません。**

`total injected 8,123/8,123   missing 0` と出れば想定どおりです。

### 8. 確認する

**`08_最後の確認をする.bat` をダブルクリックします。**

作ったファイルを 1 つずつ読み直して、ゲームが起動時にするのと同じ検査を掛けます。

**44 本すべてが `mismatches=0` になり、「導入して問題ありません」と出ることを確認してください。**
1 件でも合わない場合は、そのまま入れるとゲームが起動しなくなります。

### 9. ゲームに置く

**`09_ゲームに置く.bat` をダブルクリックします。**

**ここではじめてゲームのフォルダに書き込みます。**

まず「何が置かれるか」の一覧が表示されます。それを見てから、
`y` を入力して Enter を押すと実際に置かれます。
やめる場合は何も入力せずに Enter を押してください。

`y` と答えたあと、置く直前にもう一度すべてのファイルを検査します。
1 件でも合わなければ、何も置かずに中止します。

置いたファイルの一覧は、このツールと同じフォルダの `installed.json` に記録されます。
**元に戻すときに使うので消さないでください。**

### 終わったら

作業用フォルダの中身は消して構いません。
ただし**控え（`original_Sounds_INT`）だけは残してください。**元に戻すのに要ります。

**既定では、この控えも作業用フォルダの中にあります。フォルダごと消さないでください。**
まとめて消したい場合は、先に控えを別の場所へ移してから、その場所を `config.ini` の
`original` に書いてください。

## 元に戻す

**`99_元に戻す.bat` をダブルクリックします。**

確認を求められるので `y` を入力して Enter を押します。
控えておいたファイルが書き戻され、音声は英語に戻ります。

ゲームは終了しておいてください。起動していると書き換えられません。

## うまくいかないとき

**`.bat` をダブルクリックしても、画面が一瞬出てすぐ消える。**
`gow2jp.bat` を直接ダブルクリックしていないか確認してください。
番号の付いたファイル（`00_` や `03_` で始まるもの）を使います。

**設定ファイルが見つからないと言われる。**
`config.ini` が `config.ini.txt` になっている可能性が高いです。
エクスプローラの「表示」から、ファイル名の拡張子を表示する設定にして確かめてください。

**ゲームの音が「全部」鳴らない。**
`98_音が出ないとき.bat` をダブルクリックしてください。
`Binaries\OpenAL32.dll` を OpenAL Soft に差し替えている場合に起きます。
差し替えていなければ、この現象は起きません。日本語化とは関係のない話です。

**カットシーンが無音になる。**
**日本語化の前からそうです。**「既知の制約」を読んでください。

**一部の台詞だけ英語のまま鳴る。**
これで正常です。360 版に無い音声と、UI・武器まわりの 88 本は英語のまま残ります。

**ゲームが起動してすぐ落ちる。**
`99_元に戻す.bat` で剥がしてから、手順 7 と手順 8 をやり直してください。
手順 8 で `mismatches` が 0 でないまま置いた場合に起きます。

**手順 4 で画面が出たまま戻ってこない。**
umodel は引数なしで起動すると画面が開きます。
番号の付いた `.bat` から実行していれば起きません。

**日本語が文字化けする。**
番号の付いた `.bat` を使わずに中の Python を直接動かした場合に起きることがあります。
`.bat` から実行してください。

## 既知の制約

- **事前レンダリングのカットシーン（`.bik`）は英語のままです。**
  Hollow ではムービーの音声が最初から一切鳴りません。日本語化の副作用ではなく、
  何も手を加えていない起動時の Epic ロゴすら無音です。移植版そのものの問題と思われます。
  日本語版に組み替えるスクリプトは同梱していますが、**現時点で入れても聞こえるものは変わりません。**
- **UI 音声・武器まわりの一部 88 本は英語のままです。** 言語別ではない場所に置かれているためです。
- **字幕とメニューの表示は英語のままです。** このツールは音声だけを差し替えます。
- 360 版に音声が無いものは英語のまま残ります。

## そのほかの機能

上の手順では使いませんが、次のものも用意しています。
使うには黒い画面から `gow2jp.bat <名前>` の形で実行します。

| 名前 | 内容 |
|---|---|
| `config` | 読み込んだ設定と、ツールが見つかるかどうかを表示します |
| `openal` | 音声デバイスの設定を調べます（`98_` が呼んでいるものです） |
| `bik` | カットシーンの `.bik` を日本語版に組み替えます（現時点では効果がありません） |

このほか、`inject.py --selftest <ファイル>` で、
差し替えを 0 件にして組み立て直したものが元と一致するかを確かめられます。
